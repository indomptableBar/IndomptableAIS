Sources de données

Activez une ou plusieurs sources : leurs messages sont fusionnés par MMSI, dédoublonnés et horodatés à la seconde près. Les clés et réglages restent dans ce navigateur.

Relais local

Les navigateurs ne peuvent ouvrir ni connexion TCP/UDP ni requête vers les API qui refusent le CORS. Le relais fourni (sans dépendance) fait le pont : node ais-relay.mjs, puis ouvrez http://localhost:8787 — il sert aussi cette page, ce qui garantit l’affichage des tuiles OpenStreetMap.
